# Сайт правил Azure Shadows

Статический сайт: 96 правил группы и вкладка с сообщениями чата. Тёмная тема, открывается офлайн (`index.html` двойным кликом), заливается на любой хостинг.

## Живой чат

В папке `server/` лежит небольшой сервер: он через Telegram API читает группу и отдаёт последние сообщения сайту.

Запуск:

```
cd server
npm install
node server.mjs
```

Открывать `http://localhost:8787`. Вкладка «Живой чат» обновляется сама каждые 10 секунд.

Для работы нужен вход в Telegram на этом компьютере: переменные `TELEGRAM_API_ID` и `TELEGRAM_API_HASH` и файл сессии `%USERPROFILE%\.mcp-telegram\session` (его создают Telegram-инструменты при первом входе). Сессия используется только на чтение: сервер ничего не отправляет в группу.

## Без сервера

Сайт показывает сохранённый срез из `data/messages.json`. Обновить его можно одним из двух способов: вписать последние сообщения группы в файл вручную или запустить сервер выше, пока он работает, вкладка показывает чат живьём.

## Файлы

- `index.html`, `styles.css`, `app.js` — страница: вкладки, правила, лента сообщений.
- `rules.js` — 96 пунктов правил.
- `data/messages.json` — сохранённый срез для оффлайна.
- `server/server.mjs` — локальный сервер для живого чата.

## Залить на хостинг

**GitHub Pages.** Репозиторий, файлы в корень, Pages → Deploy from branch → main. Сайт: `https://<ник>.github.io/<репозиторий>/`.

**Netlify.** Перетащить папку `azure-shadows-site` на app.netlify.com/drop.

Хостинг даёт только срез: живой чат работает там, где запущен `server.mjs` (свой компьютер или дешёвый VPS).
